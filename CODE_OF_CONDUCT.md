# Code of Conduct

Archiscope is built for careful technical collaboration. Everyone participating in the project is expected to help maintain a constructive, harassment-free environment.

## Expected behavior

- Be respectful, specific, and patient.
- Critique ideas and code, never people.
- Assume good intent while still asking for evidence.
- Welcome newcomers and explain project conventions.
- Protect private project information and report accidental disclosure promptly.

## Unacceptable behavior

- Harassment, threats, discriminatory language, or personal attacks.
- Publishing another person’s private information without permission.
- Deliberately disruptive behavior or sustained bad-faith argument.
- Using project spaces to promote unrelated commercial or political campaigns.

## Enforcement

Report conduct concerns privately to the repository maintainer through GitHub. Maintainers may edit or remove content, close discussions, restrict participation, or ban contributors when necessary to protect the community.

Enforcement decisions should be proportional, documented privately, and focused on restoring a safe working environment.
